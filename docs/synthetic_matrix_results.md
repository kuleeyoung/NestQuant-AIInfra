# 合成矩阵乘积阶段结果

本记录用于判断算法链路是否值得进入模型实验，不代表论文复现完成。

## 配置与口径

- A、B 独立采样自标准正态分布；指标为 `mean((A @ B.T - A_hat @ B_hat.T)^2)`，与论文 §5.1 的每输出元素平均平方误差口径一致。
- NestQuant 使用 q=14、4 个 beta、候选系数 `0.5 * {1,...,50}`，并按作者代码映射 codec scale=`beta_0/q`。
- 使用固定 seed 的减性 E8 dither；当前实现将同一组 dither 跨候选 beta 复用，和作者 try-all 每个候选单独抽 dither 有差异。
- 对照包括逐行 RTN-W4、8维块 L∞ 均匀 W4 和 NestQuant 质量仿真。RTN/L∞ scale 元数据开销没有计入；NestQuant 也没有实际 pack 或熵编码。

## 结果

| 矩阵规模 n=m=k | Seeds | 方法 | 矩阵乘积 MSE/元素均值 | Seed 间样本标准差 |
|---|---:|---|---:|---:|
| 64 | 58, 59, 60 | RTN-W4，逐行 scale | 1.55339 | 0.02658 |
| 64 | 58, 59, 60 | 均匀 L∞ W4，8维块 | 0.66257 | 0.02827 |

64 尺寸三 seed 的 NestQuant 误差低于本项目逐行 RTN 参照，高于 8维块均匀 L∞ W4 参照。256 单 seed 的相对次序相同。两者量化率尚未匹配，所以这些结果不能证明某个算法更优；也不能外推到 LLM PPL、实际压缩率或推理速度。

## 码率公式核对

论文 §5.1（第 9 页）印出的表达式是 `log2(q) + (1/8) * sum_i p_i log2(p_i)`。这会因 `sum p log2(p) <= 0` 而随 beta 分布更分散而降低码率。按通常 Shannon 侧信息成本计算，符号应为减号，得到 `log2(q) - (1/8) * sum_i p_i log2(p_i)`。项目 JSON 同时保存两者，不默默修正文献，也不把任一估计称为实际文件码率。正式复现前应继续核查作者图表数据或向作者确认这一符号。
